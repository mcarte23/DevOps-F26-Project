# DevOps-F26-Project

## Project Proposal
My project proposal is for a book tracking application. You will be able to make an account, search through a list of books, and put them on shelves. You will be able to flag the estatus of the book as want to read, currently reading, and read. Once you finish a book you will be able to rate the book and write a review. You can also follow other users and see the books in their shelves and their ratings and reviews.
